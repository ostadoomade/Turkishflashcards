# ترکی A1 تا B2 — اپ تمرین گرامر و واژگان

یک وب‌اپ ساده (فقط HTML و JavaScript، بدون سرور) که روی GitHub Pages منتشر می‌شود و روی موبایل مثل یک اپ نصب می‌شود (PWA).

## انتشار روی GitHub Pages

1. در GitHub یک مخزن (repository) جدید بساز؛ مثلاً با نام `turkce`. حالت **Public** باشد.
2. همهٔ فایل‌های این پوشه را در ریشهٔ مخزن آپلود کن (دکمهٔ **Add file ← Upload files**). پوشهٔ `icons` و پوشهٔ مخفی `.github` هم باید آپلود شوند.
   - اگر آپلود از مرورگر پوشهٔ `.github` را نگرفت، مشکلی نیست؛ فقط برای روش دوم لازم است.
3. روش اول (ساده‌تر): **Settings ← Pages ← Build and deployment ← Source: Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و Save کن.
   روش دوم: در همان بخش Source را روی **GitHub Actions** بگذار؛ فایل `.github/workflows/pages.yml` خودکار منتشر می‌کند.
4. بعد از یکی‌دو دقیقه آدرس اپ بالای صفحهٔ Pages نمایش داده می‌شود:
   `https://USERNAME.github.io/turkce/`

## نصب روی موبایل

- **اندروید (Chrome):** آدرس را باز کن ← منو (⋮) ← **Install app** یا **Add to Home screen**.
- **آیفون (Safari):** آدرس را باز کن ← دکمهٔ Share ← **Add to Home Screen**.

بعد از اولین بار باز کردن، اپ بدون اینترنت هم کار می‌کند. فقط فونت وزیرمتن از Google Fonts در صورت نبودن اینترنت با فونت سیستم جایگزین می‌شود.

## اطلاعات کاربران کجا ذخیره می‌شود؟

- همه‌چیز (نام زبان‌آموز، پیشرفت، واژه‌های بلد، امتیاز) فقط در **مرورگر همان گوشی** و در `localStorage` ذخیره می‌شود. هیچ‌چیزی به سرور فرستاده نمی‌شود و حساب کاربری وجود ندارد.
- هر نفر با نصب اپ روی گوشی خودش، نمایهٔ مستقل خودش را دارد. روی یک گوشی هم می‌شود چند زبان‌آموز ساخت.
- اگر کاربر «پاک کردن داده‌های مرورگر/سایت» را بزند یا اپ را حذف کند، پیشرفتش پاک می‌شود. برای پشتیبان‌گیری: **من ← نمایش کد پشتیبان** و بعد در گوشی دیگر **بازیابی از کد پشتیبان**.
- نکته: همهٔ مخزن‌های یک حساب روی `USERNAME.github.io` یک «origin» مشترک دارند و `localStorage` بین‌شان مشترک است. کلید این اپ (`turkce-a1-v1`) یکتا است، پس با اپ‌های دیگر تداخل ندارد.
- مرورگرهای iOS ممکن است اگر چند هفته اپ باز نشود داده‌های سایت را پاک کنند؛ نصب روی Home Screen این خطر را کمتر می‌کند. کد پشتیبان را گهگاه ذخیره کن.

## به‌روزرسانی اپ

1. فایل `index.html` را عوض کن (یا فایل‌های دیگر).
2. در `sw.js` عدد `VERSION` را بالا ببر (مثلاً `v2`) تا کاربران نسخهٔ جدید را بگیرند.
3. دوباره commit کن. کاربران بار بعدی که اپ را با اینترنت باز کنند نسخهٔ جدید را می‌گیرند (گاهی باید یک‌بار اپ را کامل ببندند و باز کنند).

## فایل‌ها

- `index.html` — کل اپ (گرامر، واژگان، اعداد، پیشرفت).
- `manifest.webmanifest`، `icons/` — نصب‌پذیری روی موبایل.
- `sw.js` — کار کردن بدون اینترنت.
- `.nojekyll` — جلوگیری از پردازش Jekyll در GitHub Pages.
- `.github/workflows/pages.yml` — انتشار خودکار (اختیاری).
