# ترکی A1 تا B2 — اپ تمرین گرامر و واژگان

یک وب‌اپ ساده برای تمرین گرامر و واژگان زبان ترکی، از سطح A1 تا B2.

**این ابزار به‌طور کامل توسط Claude ساخته شده است و قرار نیست به‌روزرسانی یا توسعه پیدا کند.** پروژه در وضعیت فعلی ارائه شده و هیچ پشتیبانی یا نگهداری مستمری برای آن در نظر گرفته نشده است.

## ویژگی‌ها

- تمرین گرامر و واژگان ترکی
- تمرین اعداد و پیگیری پیشرفت زبان‌آموز
- امکان ساخت چند نمایهٔ زبان‌آموز
- ذخیرهٔ پیشرفت در مرورگر، بدون نیاز به حساب کاربری
- قابلیت نصب روی موبایل (PWA)
- امکان استفادهٔ آفلاین

## حریم خصوصی و ذخیره‌سازی اطلاعات

- اطلاعات و پیشرفت زبان‌آموز فقط در مرورگر دستگاه ذخیره می‌شود.
- هیچ حساب کاربری یا سرور اختصاصی وجود ندارد.
- با پاک شدن داده‌های مرورگر، ممکن است پیشرفت زبان‌آموز از بین برود.
- برای جلوگیری از دست رفتن اطلاعات، از بخش «من» کد پشتیبان تهیه کنید.
